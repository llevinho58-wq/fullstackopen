# Exercise 0.6: New Note in SPA Diagram

```mermaid
%%{init: {'theme': 'dark'}}%%
sequenceDiagram
    actor user
    participant browser
    participant server

    user->>browser: Types note and clicks "Save" (submit)

    Note over browser: JavaScript intercepts the submit event, appends the new note to the local list, and redraws the notes on the screen instantly

    browser->>server: POST https://helsinki.fi
    activate server
    Note over server: The server receives the JSON data and saves the new note to the database
    server-->>browser: HTTP status code 201 (Created)
    deactivate server
```
